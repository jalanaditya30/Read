# Market Research Reader

Free, no-AI, no-backend stock research text-to-speech reader.

## Modes
- **Smart Mode:** local rule-based extractive summary focused on finance/investing terms.
- **Word-for-Word:** reads the pasted text in order.

## Cost
₹0. No API, account, or server required.

## GitHub Pages
Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)` → Save.

Then open the Pages URL in Chrome/Edge. On Android, ensure a system text-to-speech engine such as Speech Services by Google is enabled.

Audio is generated by the device and pasted text is not uploaded by this app.
